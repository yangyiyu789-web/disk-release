简单查盘器 1.1.3
本地磁盘占用检查与软件关闭工具。
适用：64 位 Windows 10/11，.NET Framework 4.8 或更新版本。

使用方法

1. 连接磁盘并选择盘符，点击“重新检查”。新插入的磁盘可用“更多 → 刷新磁盘”更新。
2. 在软件列表中查看占用文件，点击行末的详情按钮可查看完整路径与进程信息。
3. 保存工作，勾选需要关闭的软件，再点击底部“关闭所选”。正常关闭会保留软件自身的保存提示。
4. 如果选中的软件全部需要强制结束，底部按钮会显示“强制结束…”。点击后须核对名单并确认。
5. 如果同时选择了可正常关闭的软件和后台进程，会先尝试正常关闭；重新检查后，对剩余后台进程可再明确选择强制结束。
6. 软件出现保存提示时，请自行保存或取消，再重新检查占用；不要为绕过保存提示而强制结束。
7. 也可使用“更多 → 强制结束所选…”，核对名单并确认。

强制结束可能丢失未保存内容或中断写入。系统关键进程受到保护。
普通权限下结果不全时，可使用“更多 → 管理员运行”重新检查。

范围与磁盘移除

本版本仅检查占用并关闭所选软件，不执行磁盘弹出或强行卸载。
关闭软件不代表磁盘已可拔出。如需移除，请使用 Windows 的安全弹出功能，
确认 Windows 允许移除后再拔线；仍然失败时请等待后台任务结束或手动处理。

资源管理器不显示在软件列表；本版本不会自动关闭文件夹，
也不会为了解除占用而结束 explorer.exe 整个进程。
需要时，可用“更多 → 关闭相关文件夹”手动关闭目标磁盘文件夹；
多标签窗口中的其他标签可能一起关闭。此操作不会随“关闭所选”自动执行。

扫描受权限、系统接口和进程状态影响。空列表不保证磁盘没有占用；
系统服务、驱动、杀毒扫描和正在进行的写入仍可能阻止 Windows 安全弹出。

安装与卸载

运行“简单查盘器-安装包-1.1.3.exe”，按提示安装到当前用户的本地磁盘。
不要安装到准备移除的移动磁盘。可选创建桌面快捷方式，也可从开始菜单打开。
安装完成不自动启动，不添加开机启动，不安装驱动或后台服务。

卸载可从 Windows“设置 → 应用”或开始菜单中的卸载入口进行。
卸载只移除本工具安装的文件及快捷方式，不删除磁盘中的个人文件。

隐私与文件真实性

本工具在本机运行，不联网，不上传路径或进程列表。
安装包和程序未数字签名，Windows 可能显示“未知发布者”。
请仅使用你信任的交付文件；项目提供完整源码与构建脚本。
